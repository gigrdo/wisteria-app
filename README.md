# Wisteria

Wisteria is a health-focused web application designed to help users explore herbal support options based on symptoms and body systems.

Built with JavaScript, Node.js, Express, and MongoDB, the project focuses on creating thoughtful and accessible digital experiences inspired by healthcare and natural wellness.

---

## Features

- Browse herbs and their uses
- Explore symptoms and body systems
- REST API structure
- MongoDB integration
- Scalable backend architecture

---

## Tech Stack

- JavaScript
- Node.js
- Express
- MongoDB
- HTML
- CSS

---

## Status

Currently in active development.

Future improvements include:

- CRUD admin panel
- Dynamic filtering
- Improved frontend experience
- Better symptom navigation
